# Atelier 8.1 : tests unitaires avec *vitest*

## Mise en place de l'environnement de test

1. Installez vitest en dépendance de développement
```bash
npm init -y
npm i -D vitest
```
2. Créez un fichier vitest.config.js à la racine de votre projet dont le contenu est

```javascript
import { defineConfig } from 'vitest/config'

export default defineConfig({
  test: {
    globals: true,
    coverage: {
      reporter: ['html'],
      reportsDirectory: './tests/coverage'
    },
    environmentMatchGlobs: [
      [
        'tests/*/*.test.[c|m]js',
        'node'
      ]
    ],
    exclude: ['node_modules']
  }
})
```
3. Modifiez le package.json en ajoutant dans la partie script les lignes suivantes 

```json
"scripts" : {
  "test": "vitest"
}
```

4. Pour lancer les tests,
```bash
npm run test
```

## Énoncé

1. Avec l'approche [TDD](https://www.ionos.fr/digitalguide/sites-internet/developpement-web/quest-ce-que-le-test-driven-development/) (pour simplifier, écrivez vos tests en premier avant d'écrire vos fonctions métiers), écrivez des tests avec les fonctionnalités incluses pour le testinf de Node pour tester les fonctions mathématiques suivantes à implémenter :
- La somme entre 2 nombres
- La somme entre x nombre (d'au moins 1 nombre à l'infini)
- La division entre 2 nombres
  - Si le diviseur est égal à 0, votre fonction déclenche une exception à l'aide de l'instruction suivante
  
    ```js
    throw new Error('division by 0 impossible')
    ```
  
    Donc dans votre test, vous devez vous attendre à récupérer un objet de type Error avec le message d'erreur "division by 0 impossible"
  
  - Si le diviseur est différent de 0, l'opération s'effectue
- Refactoriser la somme pour faire cette opération avec plusieurs nombres (minimum 2 nombres, pas de maximum)
